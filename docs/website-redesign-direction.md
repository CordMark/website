# CordMark Website Redesign Direction

最終更新: 2026-09-03
状態: 構想メモ / 次のデザイン・実装作業への引き継ぎ資料

## この文書の位置づけ

この文書は、CordMarkの会社Contextと現在のローカルサイトを読んだうえで考えた、Webサイトのリデザイン方向をまとめたものです。

完成仕様や承認済みデザインではありません。次に作業する人が、単に見た目を整えるのではなく、「CordMarkをどのような会社として伝えるか」から設計を始められるようにするための土台です。

アニメーションについては、技術、ライブラリ、秒数、イージングなどの実装方法をこの文書では決めません。どのような意味や感覚を担わせたいかだけを記載します。

## 現在のサイトに対する認識

現在のサイトは、実装力や支援内容を具体的に伝える点では一定の役割を果たしています。一方、ファーストビューから「AI Native」「Company OS」「業務改善」「KPI」「実装」が前面に出るため、最初に受ける印象は「AI導入・AI活用を支援する会社」に近くなっています。

主な課題は、アニメーションが少ないことそのものではありません。より大きな課題は、CordMarkがなぜ存在するのか、AIを何のために使うのかという思想が、支援内容の後ろに置かれていることです。

現状のまま動きや装飾だけを増やすと、「AI支援会社としての見せ方」が洗練されるだけで、会社の本質との距離は残る可能性があります。先に物語の順序とデザインの人格を変え、その意味を強めるために動きを使うべきだと考えます。

## 伝えるべきCordMarkの中心

CordMarkの中心は、AIそのものでも、効率化そのものでもありません。

> テクノロジーによる物質的な充足を、精神的な豊かさへ還元する。

AIによって生産力や実行能力が大きくなったとき、その力を単に仕事量や競争力の拡大へ使うのではなく、人が自ら考え、決め、創造し、他者と関わるための時間と自由へ戻していく会社です。

AIは人間の意思に置き換わる存在ではなく、人間の意思を現実へ変える力として扱います。

この関係を、サイト全体の骨格にします。

```text
Human Intent
→ Decision
→ Technology / AI
→ Action
→ Time and Freedom
→ Human Flourishing
```

## サイトを見た人に残したい印象

最初に残したいのは、「AIに詳しい会社」だけではありません。

- 技術の先にある、人間の生き方まで考えている会社
- 大きな思想を持ちながら、現場で実装し、検証する会社
- AIに人間の判断を明け渡すのではなく、人の意思を強くする会社
- 短期的な流行ではなく、長い時間軸で未来をつくろうとしている会社
- 少し変わっていて、知的で、話してみたくなる会社

サイトの読後感は「依頼できることが分かった」だけでなく、「この会社が見ている未来をもう少し知りたい」が理想です。

## ポジショニング

### CordMarkが目指す見え方

- 人間の意思とテクノロジーをつなぐ会社
- AI時代の新しい働き方を、思想と実践の両方からつくる会社
- CordMark OSを中心に、組織の意思決定と実行をつなぐ会社
- 顧客の現場で成果を出し、得た知見をプロダクトへ還元する会社

### 避けたい見え方

- AIツールの導入代行会社
- 何でもAI化するDXコンサルティング会社
- 青いグラデーションと抽象的な3Dだけで構成された、一般的なAI企業
- 思想だけを語り、実際に何をしているか分からない研究集団
- 縄文を表層的な装飾や和風演出として消費するブランド

思想と実務のどちらかに寄せ切るのではなく、両方が同じ会社の中でつながっていることが重要です。

## 想定する主な閲覧者

1. CordMarkへの依頼や協業を検討する企業・責任者
2. CordMark OSやAI時代の組織づくりに関心を持つ人
3. 将来一緒に働く可能性がある人
4. DotCraftなどを通じてCordMarkを知り、会社の背景を確かめに来た人

最初のページで全サービスの詳細を説明し切るより、まず会社の考え方と現在の取り組みの関係を理解してもらい、関心に応じて詳細ページへ進める構造が合います。

## 推奨するトップページの物語

### 1. Hero — 人の意思を主語にする

最初の画面では、AI、Company OS、支援メニューを主語にしません。人間の意思を中心に置きます。

コピーの方向例:

> 人の意思を、現実へ。<br>
> AIは、そのためにある。

補足では、AIを人間の代替ではなく、人が望む未来をより大きく実現する力として捉えることを伝えます。

### 2. Purpose — 会社が存在する理由

CordMarkのPurposeを、短く、大きく、余白を使って提示します。

> テクノロジーによる物質的な充足を、<br>
> 精神的な豊かさへ還元する。

この言葉を単独の標語で終わらせず、次の因果関係を示します。

```text
生産力が上がる
→ 実行負担が減る
→ 人に余力が生まれる
→ 人が考え、決め、創造できる
→ 時間、自由、尊厳、他者との関わりへ還元される
```

### 3. Current Focus — いまは「働く」から始める

CordMarkの視野は人の生き方全体にありますが、現在の主領域はWorkです。この大小関係を明確にします。

「AI支援が会社のすべて」ではなく、「長期的なPurposeを実現する最初の領域として、現在は人の働き方に取り組んでいる」と説明します。

### 4. CordMark OS — 思想を実装する中心Product

CordMark OSを、単なるCompany OSやナレッジ管理ツールとしてではなく、PurposeをWork領域で実装する中心Productとして配置します。

伝えるべき中心の流れ:

```text
Signal
→ Question
→ Human Decision
→ Development-ready Specification
→ Action
```

重要なのは、AIが自律的にすべてを決めることではなく、人間が決めるべきことを見つけ、そのDecisionを日々の仕事へ接続することです。

### 5. What We Do — 三つの事業を関係として見せる

現在の事業は、別々のサービス一覧ではなく、循環する三つの実践として見せます。

1. CordMark OSの企画・開発・展開
2. 組織・業務改善、AI駆動開発の導入・教育・伴走
3. 顧客の課題に対する受託・共同開発

受託・共同開発で現場を理解し、支援とCordMark OSへ知見を還元する関係まで伝えます。

### 6. Principles — 判断の仕方を見せる

Canonical Contextにある四つのPrinciplesを、そのまま会社の人格として見せます。

1. 面白さを見失わない。
2. 遠くを見据えて今を決める。
3. 摩擦を価値に変える。
4. 確かさを積み上げる。

抽象的なValue一覧ではなく、CordMarkが実際にどのように考え、選ぶ会社なのかが分かる短い文章を添えます。

### 7. Origin — CordMarkと縄文

CordMarkという名前が縄文時代の縄目に由来する背景を説明します。

過去を理想化するのではなく、豊かな資源を人間の豊かな暮らしへつなげるという問いを、AI時代に更新する姿勢を伝えます。

サイト全体の視覚的なモチーフも、この「縄目」「痕跡」「つながり」から発想できます。ただし、土器の写真や古代風の意匠を前面に出す必要はありません。

### 8. Two Horizons — WorkからLifeへ

現在と長期構想を、二つの時間軸として見せます。

- Now / Work: 組織の意思と実行をつなぎ、人が判断と創造に集中できる働き方をつくる
- Next / Life: 遊び、学び、競技、創作、交流など、人が自ら行う価値のある活動へ広げる

DotCraftやLaplaceは、唐突な別事業としてではなく、この長期構想を探索している具体的な活動として接続すると理解しやすくなります。

### 9. Contact — 営業色を弱め、対話へつなぐ

「無料相談」「AI導入の相談」よりも、まだ言葉になっていない構想や問いから話せる印象が合います。

コピーの方向例:

> 何をつくるかから、一緒に考えましょう。

## ビジュアルの方向

### 全体の人格

目指すのは、未来的でありながら冷たくない、知的でありながら難解すぎない、静かだが強いデザインです。

「最新AI」「高速」「自動化」を連想させる一般的なテック企業の表現ではなく、人間の時間、手触り、痕跡、思考の深さを感じるものにします。

### 色

- ベース: 温度のある紙色、生成り、淡い砂色
- 文字: 真っ黒ではない墨色
- アクセント: 縄文土器や土を直接模倣しない、深い朱・焼けた銅・赤土系
- 補助色: 鉱物や石を思わせる鈍い灰色、必要に応じて深い緑
- 暗いセクション: 青黒ではなく、炭や夜の森に近い色

現在の鮮やかな青を中心にしたAI企業らしい配色からは距離を取ります。

### タイポグラフィ

- 基本は現代的で読みやすいサンセリフ
- Purposeや問いかけなど、人間の思想を語る箇所に限り、明朝系や有機的な書体を慎重に組み合わせる
- 英語の大文字ラベルは情報整理に使うが、英語がブランドの中心に見えない量に抑える
- 大きな言葉と長い余白を使い、すべてをカードに閉じ込めない

### 形とモチーフ

- 縄目を抽象化した線、交差、結び目、連続する痕跡
- 人の意思から実行へ情報が流れる様子
- 完全な幾何学ではなく、わずかな揺らぎを持つ線
- Editorialなグリッドと、そこから少し外れる有機的な要素
- 写真を使う場合は、一般的な会議風景やAI生成の人物ではなく、人の手、制作の痕跡、場所、実際の活動が感じられるもの

## 動きに持たせたい意味

次の実装担当がアニメーションを設計するときは、動きを「高機能に見せる装飾」ではなく、CordMarkの考え方を理解する手段として扱います。

### Hero

離れていた線や情報が、人の意思を中心に結び直され、実行へ向かう感覚。速く飛び交うデータではなく、ゆっくり関係が見えてくる動きが合います。

### Purpose

生産力、余力、意思、時間、豊かさが、一方向の効率化ではなく、人間へ戻ってくる流れとして感じられること。

### CordMark OS

SignalがQuestionになり、人間のDecisionを通ってSpecificationとActionへ変わる因果関係を、順番として理解できること。

### 縄目のモチーフ

線がただ揺れるのではなく、交差し、残り、次の形の土台になること。意思決定や仕事のContextが組織に蓄積される感覚と接続できます。

### 全体

- 動きは速さよりも、意思、蓄積、接続、余白を感じさせる
- Scrollのたびにすべてが派手に出現する構成は避ける
- 重要な言葉を読む時間を奪わない
- 動きを減らす設定でも意味と階層が失われないようにする

## 既存サイトから残したいもの

- Contact Formと送信処理
- Privacy Policy
- 現在存在する各Service詳細ページの情報
- Header、Footer、Mobile Navigationの基本機能
- DotCraftへの導線
- CordMark OS、AI駆動開発、共同開発という実務上の信頼につながる具体性

見た目やページ構成をそのまま残すという意味ではなく、すでに実装されている機能と事業説明を失わないという意味です。

## 作業上の注意

- ローカルの`cordmark-website`には、現時点で多数の未コミット変更があります。次の実装担当は、既存差分を消さず、現在の作業内容を前提に変更する必要があります。
- まずトップページを新しい物語へ切り替え、その後にAbout、各Service、Contactの順で世界観を揃えるのが安全です。
- 現在のOG画像は、青いAI企業の印象と「AIを、会社の使える仕組みに」という旧メッセージを持っています。トップページの方向が確定した後、別途更新が必要です。
- 実績数、導入社数、公開可能な顧客名などは、根拠が確認できない限り追加しません。
- CordMark OSは開発・検証中です。完成済みProductとして誤認させない表現にします。
- 縄文に関する断定的な歴史表現は避け、CordMarkがそこから何を読み取っているかとして記述します。

## まだ決めていないこと
